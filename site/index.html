ENCRYPTED FEATURE BANK

Graph compilation is plaintext at the client. This prototype is not encrypted training, private-topology evaluation, remote key isolation, or a production security guarantee.

WHY A FEATURE BANK?

Move the graph work.
Keep the model explicit.

For a fixed graph operator, the client can compute Chebyshev-transformed features once. The readout then uses dense projections of those features, a polynomial activation, and a final classifier.

This laboratory checks the algebra with an independent direct oracle. It demonstrates numerical equivalence for the selected model; it does not establish accuracy on unseen data, conceal the default plaintext bank, or prove security.
